# Consulting-Workflow-Automation

A Python-based workflow automation system designed to transform business data into actionable recommendations.

## Features

- Data ingestion and processing
- KPI calculation using pandas
- Rule-based recommendation engine
- SQL database storage
- Automated Excel reporting

## Technologies

- Python
- pandas
- SQLite
- Excel

## Example Workflow

Input:
Store sales, inventory, and returns data.

Output:
Business recommendations based on predefined operational rules.
